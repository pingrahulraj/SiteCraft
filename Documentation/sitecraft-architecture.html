1. Executive verdict

QuestionVerdict
Is serverless static-first on AWS viable?RECOMMENDATIONYes. Idle cost ≈ ₹1.1k/month. Compute, DB and API are near-zero per site. CloudFront egress is the only large cost (≈₹10.4 per GB all-in).
Is it viable uncapped?CALCULATIONNo. Mixed traffic with no caps costs ≈ ₹182/site/month, above a ₹99 price. The top 3% of sites generate ~78% of CDN cost. Bandwidth caps are a product requirement.
Permanent free public hosting?RECOMMENDATIONNo. Free = LOCAL + DRAFT + 7-day PREVIEW. Published sites require an active entitlement. Free hosting also attracts phishing, which puts the AWS account at risk.
PricingRECOMMENDATIONLaunch ₹99 Starter (5 GB) and ₹199 Pro (12 GB). ₹49 Lite only as subdomain-only, 2 GB, annual prepay. Overage ₹15/GB with a spend ceiling.
Margin at scaleCALCULATIONBlended gross margin: 45% @100 sites, 62% @1k, 72% @10k, 73% @100k (₹99 plan, before support, CAC, tax).
Architecture changes from your hypothesisRECOMMENDATIONPublish = materialise files to live/{tenant}/ via server-side S3 copy (no edge KV lookup). Custom domains gated to paid plans (₹9/domain tenant fee). Separate user-content domain and AWS account boundary. Everything else holds.

RECOMMENDATIONSingle surface: REST /v1 described by OpenAPI; CLI and MCP server are thin clients of it (the MCP can be a Node/Go stdio binary; it never needs AWS credentials). Responses include usage_remaining so agents self-throttle. Errors are machine-readable (code, path, fix) to save agent retries and tokens.

13. AWS IaC deployment plan

RECOMMENDATIONAWS CDK (TypeScript). Reasons: CloudFormation underneath means no state backend to run, same-day resource coverage via L1 constructs (new CloudFront SaaS Manager resources first appear there), rollback built in, and the Vue/TS team already writes TypeScript. Terraform adds state, locking and lagging provider support; raw CloudFormation costs too many lines.

EnvironmentDecision
DEVLocal only: DynamoDB Local + MinIO + sam local/Docker Lambda emulation. Cost ₹0.
STAGINGSeparate nonprod account, same CDK app with -c stage=staging, deployed on demand, cdk destroy after release testing; no WAF, no PITR, 1-day log retention. Idle ≈ ₹0.
PRODUCTIONSeparate prod account(s): control-plane and customer-content (blobs/live/preview/CloudFront). Consolidated billing through AWS Organizations (free).

Three always-on environments are not needed: use two accounts plus a staging stack that is deployed on demand.

FoundationOrg/accounts, IAM roles (least privilege per Lambda; separate deploy role), GitHub OIDC role for CI, KMS key, Budgets ($20/$50/$100 + 80% forecast), Cost Anomaly Detection, SNS email, budget action → deny-policy on deploy role

Must be right now (expensive to change later)

  • tenant_id on every record, S3 key and meter: never retrofit.
  • Separate user-content domain and AWS account: cannot be migrated cheaply once customers have custom DNS pointing at you.
  • Content-addressed blobs + immutable releases + manifest.
  • Entitlement model and usage ledger (idempotent events).
  • Public OpenAPI /v1 with versioning and error codes (CLI/MCP depend on it).
  • Custom-domain CNAME target: use a SiteCraft-owned name (cname.sitecraft.site) so the CDN vendor can be swapped without asking customers to change DNS.
  • Money in integer paise + currency, GST fields in invoice model.

18. v1.1 changes: avoiding CloudFront costs

ADR-002 · Edge on Cloudflare, control plane on AWS · Status: Proposed · supersedes ADR-001 items 4, 5 and the CDN parts of 3, 6, 11
ContextCloudFront egress makes uncapped blended COGS ≈ ₹180/site and forces small plans. Cloudflare R2 has free egress; requests become the cost (₹33.5/M).
Decision
  1. R2 holds blobs, live, preview, manifests. Clients upload to R2 by presigned URL. Publish copies changed files only.
  2. One Worker routes host → KV → R2, applies state (suspended/preview/expired) and headers. KV is a cache of DynamoDB state.
  3. Custom domains through Cloudflare for SaaS; paid plans only; cname.sitecraft.site as vendor-neutral target; separate Cloudflare account for customer content.
  4. AWS stays: HTTP API, one Lambda, DynamoDB (sc_core, later sc_commerce), SES, SSM, Budgets, CDK. Own auth (Google + email OTP + PAT), no Cognito.
  5. Plans: Free (50 MB, 100k req, badge, subdomain, only after abuse controls), Starter ₹99 (1M req, 1 domain), Pro ₹199 (3M req, 2 domains), Commerce ₹499. Overage ₹60/M req with 3× ceiling.
  6. Metering by adaptive polling; kill switch via KV (≤ 60 s). Free sites daily, paid hourly.
  7. Commerce is a module on /_sc/commerce/*; merchant-owned gateway keys; no card data; no funds held.
  8. Fallback: weekly S3 replica of paid blobs + CloudFront/S3 stack kept deployable; failover drill quarterly.
ConsequencesBlended CDN cost ≈ ₹8.9 vs ₹180. Starter blended GM ≈ 88%, 100k paid sites ≈ 87%. Free tier expected ≈ ₹0.4/site, worst ₹3.7. 10M-site model profitable at ≥ 1–2% paid conversion (people cost dominates). New dependency on Cloudflare (outage, terms, 50k hostname cap).
Verify before buildCloudflare prices and content-serving terms on official pages; Enterprise quote at 25k domains; legal advice on payments and takedowns; measured traffic classes from beta.
